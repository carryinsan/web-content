Developer Guide: Injecting Sources into AI

The Web Tacker API is designed specifically to act as an aggressive, high-concurrency fetching layer for AI applications (like RAG systems). It combines discovery (search) and deep extraction into a single, time-bounded edge request.

How to use it in your AI App

When a user asks your AI a question requiring web context, construct a query and call this API:

const response = await fetch('https://[YOUR_VERCEL_DOMAIN]/api/combine?query=latest+spacex+launch&count=10');
const data = await response.json();

// 1. Check for global success
if (!data.success) {
    console.error("Critical failure:", data.error);
    return;
}

// 2. Filter out failed extractions (sites that blocked the scraper)
const validSources = data.results.filter(item => 
    item.extraction && item.extraction.success
);

// 3. Format the clean text for your LLM context window
let aiContext = "Here is the latest web information:\n\n";
validSources.forEach((source, index) => {
    // Truncate content to save tokens!
    const cleanText = source.extraction.content.substring(0, 1500); 
    aiContext += `[Source ${index + 1}: ${source.url}]\n${cleanText}\n\n`;
});

// 4. Send aiContext to your LLM...

Critical Constraints & Safeguards

1. The 15-Second Edge Limit:
Vercel Free/Pro Edge functions have a hard kill-switch at 10-15 seconds. This API has an internal failsafe that triggers at 14.5 seconds. If you request 50 extractions and 45 finish in time, the API will abort the remaining 5 and immediately return a HTTP 200 with the 45 successful results rather than letting Vercel throw a 504 Timeout error.
2. Handling Failed Extractions:
Because this API uses parallel execution, one blocked site will not crash the others. However, you must check item.extraction.success === true before trying to read item.extraction.content. Sites heavily protected by Cloudflare JS challenges may fail and will have success: false.
3. Token Limits:
This API attempts to strip HTML to return raw text, but web pages can be massive. You are responsible for chunking or truncating item.extraction.content on your server before sending it to OpenAI/Anthropic to avoid exceeding token context limits.
